# 微记 mini-post

一个只保存在本机的轻量动态记录工具，用纯 HTML + CSS + JavaScript 写成，无框架、无构建、无后端。

## 功能

- 发布动态：输入文字后点击「发布」或按 `Ctrl / ⌘ + Enter`，内容立即出现在时间线顶部
- 浏览时间线：按发布时间倒序展示，包含头像占位、昵称、相对时间与正文，正文保留换行
- 输入校验：内容为空时按钮禁用；上限 280 字，实时显示剩余字数并提示超限
- 本地持久化：数据存入浏览器 `localStorage`（键名 `minipost.posts.v1`），刷新页面后仍在
- 空状态引导：没有动态时展示引导文案，可一键聚焦到输入框

## 运行

方式一：直接双击 `mini-post/index.html`，用浏览器打开。

方式二：启动一个本地静态服务器：

```bash
cd mini-post
python -m http.server 5173
```

然后访问 <http://127.0.0.1:5173/>。

## 数据说明

所有动态只保存在当前浏览器的 `localStorage` 中，不会上传到任何服务器；清理站点数据或更换浏览器会导致内容不可见。
